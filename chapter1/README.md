## CLONE PROJECT REPOSITORY
1. Open your Bash or cmd Terminal
2. Copy the following command into your terminal: `git clone -b golang --single-branch https://github.com/CyberLas/AlgorithmsCoding.git`
3. Wait for the Repository to download
4. Enter the repository and follow the steps in [RUNNING EXERCISES](#running-exercises)
<br/>


## RUNNING EXERCISES
1. Open your Bash or cmd terminal
2. Enter the folder via terminal, for example: `cd [folder name]`
3. Then run the exercises you want with the following command: `go run [file name].go`
4. Finally enter the data requested by the program
